# 改用 g0v pcc-api 查詢標案，不直接查詢政府電子採購網

政府電子採購網沒有官方即時查詢 API，只提供延遲約兩個月的批次 XML 下載，無法滿足每日抓當日/近期標案的需求；直接對官網查詢頁面做自動化查詢，官網著作權聲明有「禁止未經同意大量轉載內容」的文字、robots.txt 內容也不明，屬合規灰色地帶。改採 g0v 社群維護的 `pcc-api.openfun.app`：資料近乎即時（實測當日資料已可查得）、涵蓋所需的機關名稱/標案名稱/公告日/截止投標/開標時間/預算金額等欄位、有正式 API 文件、近一個月內仍持續有 commit。代價是依賴一個非官方、社群維運的第三方服務：資料授權條款目前未能完整確認，且若該服務中斷或改版，程式需要跟著調整。
