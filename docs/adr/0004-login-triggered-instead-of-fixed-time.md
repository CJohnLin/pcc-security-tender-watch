# 改成「登入時觸發」，不是固定每天 8:00

固定時間觸發（每天 8:00）在這台網域帳號（`REHFELDTORG\john.lin`）的電腦上反覆漏跑：這台機器登出後，「只有登入時才執行」的排程完全不會補跑（連失敗記錄都沒有），連續發生過好幾次。試過改成「不論登入與否均執行」，但這台機器是網域集中管理，帳號沒有「以批次工作登入」（Log on as a batch job）權限，且使用者沒有本機管理員權限去開這個權限（改網域原則需要 IT 協助，目前不可行），改完之後排程反而每天固定觸發兩次登入失敗。

改成 Windows 工作排程器的「登入時」觸發，不指定固定時間：使用者實際登入電腦的那一刻就會觸發，不會因為登入時間點錯過某個固定時刻而整天不跑。因為觸發時機不再是固定的，程式自己要判斷「現在該不該真的執行」（`main._unattended_skip_reason`）：

1. 今天已經成功執行過一次（用 `last_success_date.txt` 記錄），不重複執行——避免同一天登出又登入多次，重複建立好幾封草稿
2. 現在時間還沒到 `EARLIEST_RUN_HOUR`（預設 8 點），不執行——太早登入（例如提早開機工作）不會提前觸發
3. 今天是假日（週末或國定假日，見 ADR 前一版邏輯），不執行

失敗（查詢過程出錯）不會寫入成功標記，下次登入仍會重新嘗試，不會被「已經跑過」擋住。
